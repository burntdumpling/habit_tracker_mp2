# Трекер привычек

Командный учебный проект ЮФУ по дисциплине «Междисциплинарный проект 2». Приложение для Android помогает планировать привычки, отмечать их выполнение и следить за прогрессом.

## Возможности

- Регистрация и вход в аккаунт.
- Создание, редактирование и удаление привычек. Для каждой можно задать расписание, время суток и цель на день.
- Календарь и отметки выполнения по датам.
- Статистика с графиками, процентом выполнения и сериями дней подряд.

## Стек

- [Android-клиент](android/) — Kotlin, Jetpack Compose, Retrofit.
- [Сервер](backend/) — Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic.

## Локальный запуск

1. Запустите PostgreSQL и API по [инструкции для backend](backend/README_DEV.md). После запуска документация API доступна по адресу `http://localhost:8000/docs`.
2. Откройте папку `android/` в Android Studio и соберите проект с Android SDK 36.
3. Запустите `app` в эмуляторе с Android 8.0 или новее и зарегистрируйтесь. Клиент обращается к локальному API по адресу `http://10.0.2.2:8000/`.
