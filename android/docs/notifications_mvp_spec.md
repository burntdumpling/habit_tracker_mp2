# MVP-спецификация уведомлений (Android Habit Tracker)

## 1) Цель
Этот документ фиксирует единые MVP-правила уведомлений для Android-клиента Habit Tracker, чтобы следующие этапы реализации опирались на один источник правды.

## 2) Scope
- Документ относится только к MVP.
- В MVP рассматриваются локальные уведомления на клиенте Android.
- Серверные push-уведомления в рамках этого документа не рассматриваются.

## 3) Типы уведомлений в MVP
- **Habit reminder**: базовое напоминание о привычке в запланированное время.
- **Daily completion**: уведомление при выполнении дневной цели привычки.
- **Streak achievement**: уведомление при достижении серии выполнения в **3 / 7 / 14 / 30** дней.
- **Grouped reminder**: если несколько привычек попадают в один и тот же момент, отправляется одно сгруппированное уведомление вместо набора отдельных.

## 4) Trigger rules
### Habit reminder приходит только если одновременно выполнены условия:
- глобальные уведомления включены;
- уведомления для конкретной привычки включены;
- привычка активна;
- привычка запланирована на текущую дату по frequency;
- привычка на текущую дату ещё не выполнена.

### Daily completion
- Приходит только один раз за дату, в момент когда дневная цель привычки закрыта.

### Streak achievement
- Приходит только при достижении порогов **3 / 7 / 14 / 30** дней.
- Для каждого порога уведомление отправляется один раз на факт достижения.

### Grouped reminder
- Используется, когда несколько привычек имеют одно и то же время напоминания.

## 5) Non-trigger rules
Уведомления не приходят, если:
- привычка уже выполнена;
- привычка не запланирована на выбранную дату;
- привычка в состоянии paused / finished / неактивна;
- глобальные уведомления выключены;
- reminder для этой привычки выключен.

## 6) Notification content guidelines
- Короткий заголовок.
- Короткое тело уведомления.
- Без перегруза текстом.
- Спокойный минималистичный тон.
- Мотивационная фраза допустима как короткая добавка внутри `Habit reminder` или `Daily completion`, но не как отдельный поток случайных уведомлений.

## 7) Out of scope for MVP
В MVP и в текущем шаге не входят:
- случайные мотивационные push без привязки к привычке;
- snooze / postpone;
- quiet hours / do not disturb логика внутри приложения;
- исключения уровня «отпуск»;
- серверные push-уведомления;
- сложная аналитика уведомлений;
- A/B тесты уведомлений.

## 8) Future implementation notes
Дальнейшая реализация идет по шагам:

## 9) Acceptance examples
- «Привычка запланирована на сегодня, не выполнена, reminder включён, глобальные уведомления включены -> reminder должен прийти».
- «Привычка уже выполнена до reminder time -> reminder не должен прийти».
- «Сегодня привычка не запланирована по frequency -> reminder не должен прийти».
- «Глобальные уведомления выключены -> никакие уведомления не должны приходить».
- «Пользователь достиг streak 7 -> streak achievement должен прийти один раз».
- «Три привычки имеют одно и то же время -> должен прийти grouped reminder».
- «Дневная цель закрыта сегодня впервые -> daily completion должен прийти один раз за эту дату».
